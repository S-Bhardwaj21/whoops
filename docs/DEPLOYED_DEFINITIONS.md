## 5. Cortex Search Service and Supporting Objects

The Cortex Search service indexes `COMPLIANCE_DOCUMENT_CHUNKS` (defined in section 3).

```sql
CREATE OR REPLACE CORTEX SEARCH SERVICE COLD_CHAIN_COMPLIANCE.GOLD.COMPLIANCE_EVIDENCE_SEARCH
    ON EVIDENCE_TEXT
    ATTRIBUTES SHIPMENT_ID, DOCUMENT_NAME, CLAUSE_REFERENCE, PAGE_NUMBER, SOURCE_TYPE
    WAREHOUSE = COMPUTE_WH
    TARGET_LAG = '1 hour'
    AS (
        SELECT
            EVIDENCE_ID,
            SHIPMENT_ID,
            DOCUMENT_NAME,
            CLAUSE_REFERENCE,
            PAGE_NUMBER,
            EVIDENCE_TEXT,
            SOURCE_TYPE
        FROM COLD_CHAIN_COMPLIANCE.GOLD.COMPLIANCE_DOCUMENT_CHUNKS
```

### 7f. Task

```sql
CREATE OR REPLACE TASK COLD_CHAIN_COMPLIANCE.GOVERNANCE.TASK_DETECT_COLD_CHAIN_BREACHES
    WAREHOUSE = COMPUTE_WH
    WHEN SYSTEM$STREAM_HAS_DATA('COLD_CHAIN_COMPLIANCE.GOVERNANCE.IOT_TEMP_LOGS_STREAM')
AS
INSERT INTO COLD_CHAIN_COMPLIANCE.GOLD.GOLD_COMPLIANCE_BREACHES
(
    BREACH_ID, SHIPMENT_ID, SENSOR_ID, EVENT_ID, EVENT_TS,
    TEMPERATURE_C, THRESHOLD_C, BREACH_TYPE, STATUS
)
SELECT
    'BREACH-' || EVENT_ID,
    SHIPMENT_ID, SENSOR_ID, EVENT_ID, EVENT_TS,
    TEMPERATURE_C, 8.00, 'TEMPERATURE_ABOVE_THRESHOLD', 'OPEN'
FROM COLD_CHAIN_COMPLIANCE.GOVERNANCE.IOT_TEMP_LOGS_STREAM
WHERE METADATA$ACTION = 'INSERT'
  AND TEMPERATURE_C > 8;
```

## Deployment Order

For a from-scratch recreation, execute in this order:

1. Database and schemas
2. Roles
3. GOVERNANCE tag and masking policy
4. BRONZE tables
5. Tag + masking policy application to `IOT_TEMP_LOGS.TEMPERATURE_C`
6. SILVER tables
7. GOLD tables
8. GOLD secure views
9. GOLD semantic views
10. GOLD Cortex Search service
11. GOVERNANCE tables (audit, legacy definitions)
12. GOVERNANCE stream
13. GOVERNANCE task
14. All grants (database, schema, table, view, semantic view, task, stream)
15. Ownership transfers (view, task)
16. Resume task
